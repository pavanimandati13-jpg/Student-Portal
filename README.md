## 📌 Project Introduction

The **Student Portal** is a web-based front-end project designed to provide students with an easy-to-use online interface.

The project is developed using basic web technologies and demonstrates the use of HTML for webpage structure, CSS for styling and responsive design, and JavaScript for interactive functionality.

## ▶️ How to Run the Project

### Method 1: Using VS Code

1. Download or clone the repository.
2. Open the `Student-Portal` folder in VS Code.
3. Open `index.html`.
4. Right-click on `index.html`.
5. Select **Open with Live Server**.

The website will open in your browser.

### Method 2: Directly in Browser

You can also open the `index.html` file directly in a web browser.
